# 写真の置き場所

ここに画像を置くだけでサイトに反映されます。ビルドやコードの変更は不要です。

## 使い方

ファイル名を下の「スロット名」と同じにして、このフォルダに置いてください。

```
src/assets/photos/hero.jpg      → ファーストビュー
src/assets/photos/kemuri.jpg    → 02 KEMURI の店舗外観
...
```

対応拡張子：`.avif` / `.webp` / `.jpg` / `.jpeg` / `.png`
同じ名前で複数置いた場合は **avif → webp → jpg** の順で採用されます。

## 推奨

- 長辺 2000px 程度で書き出してください（Viteが最適化します）
- 暗い店内・夜の写真は、焼き目と煙が見えるよう明るめの現像だと映えます
- `hero` は**縦位置**で撮ると、スマートフォンで最も効きます

未設置のスロットは「写真をご提供ください」という枠として表示されます。
実写真が未提供のため、AI生成画像やフリー素材での代用は行っていません。
