# 燻製塩焼鳥 けむり ／ 営業提案用デモLP

RIKKUN WEB STUDIO が店舗へ提案するための **営業用デモサイト** です。
**正式納品サイトではありません。**

---

## 目的

「集客最大化」ではなく **「注文導線の最適化」**。

Google検索・Instagramからすでに流入しているユーザーが、

店舗情報を理解する → 必要なら事前予約する → スムーズに受け取る

までを迷わず完了できる状態をつくることを目的としています。

Primary CTA は **「電話で注文する」（`tel:09044731867`）** の1つに統一。
ネット予約・予約フォーム・LINE予約・当日DM注文は実装していません
（公式Instagramで電話注文が推奨され、当日のDM注文は不可と案内されているため）。

---

## 実装方針

- **ライブラリ・外部リクエストゼロ**。HTML/CSS/JS のみ。Webフォントも読み込まず端末内蔵の明朝／ゴシックを使用。
- **JS無効でも全内容が読める**。スクロール表示のクラスはJSから付与しているため、非表示のまま残ることはありません。
- **モバイルファースト**。ワイヤーフレームがスマートフォン基準のため、SPを基準に880px以上で2カラム化。
- `prefers-reduced-motion: reduce` でモーションを全停止。
- スキップリンク / ランドマーク / `:focus-visible` / ネイティブ`<details>` によるFAQ。
- 構造化データ（FoodEstablishment）は**確認できた項目のみ**。価格・メニューは含めていません。

### TODAY の日付表示について

`assets/js/main.js` は **定休日（火・水）と営業時間（17:00〜22:00）のみ**から
「本日は定休日です」／「本日は 17:00 OPEN の予定です」を出し分けます（`Asia/Tokyo` 基準）。

**「営業中」とは断定しません。** 売切れ次第CLOSEのため、
在庫状況はInstagramまたは電話で確認する導線に接続しています。

### 店舗の更新負担

日替わりメニューはサイト側で更新しません。すでに運用中のInstagramへ誘導する設計です。
**店舗側に毎日サイトを更新する作業は発生しません。**

## TO CONFIRM（店舗ヒアリングが必要な項目）

推測で埋めず、すべて未確認のまま残しています。

1. **各メニューの価格** — `PRICE TO CONFIRM` 表示
2. **メニューの全ラインナップ** — 公開情報から確認できた7品のみ掲載
3. **燻製塩の製法・使用素材・味の詳細** — 記載なし
4. **予約ルール**（「何分前まで」等） — 「詳しい予約方法はお電話でご確認ください」
5. **予約なしでの購入可否** — FAQ を TO CONFIRM のまま
6. **焼き上がりまでの時間の目安** — 数値は設定せず、店舗確認へ誘導
7. **駐車可能台数** — 「駐車はお店の前にお願いします」のみ。台数の記載なし

### ブリーフ未受領のため既定値で実装した項目

ブリーフが `10. ACTUAL STORE VISUAL REFERENCE` の途中
（`・濃紺〜ネイビーの外壁 ・白い店舗サイン ・赤`）で終わっており、
以下のセクションは本文を受領できていません。

- Visual DNA / Image Strategy / Motion Rules / Responsive Rules
- Accessibility / SEO / Performance / Anti-template Rules

上記は**確認済みの3色と、09 WIREFRAME 内に明記された禁止事項**
（HEROを画面いっぱいにしない／写真と文字を重ねすぎない／3カード構成にしない／
テンプレート的なIAにしない）のみを根拠に実装しています。
残りの指示を受領次第、調整が必要です。

#### 判断が必要な点：明朝体のWebフォント

「国分の街角にある、知る人ぞ知る焼鳥店」という
デザインコンセプトを支えているのは見出しの**明朝体**です。

現在は Performance ルール未受領のため、**外部リクエストを一切発生させない方針**を採り、
端末内蔵フォント（Hiragino Mincho ProN → Yu Mincho → Noto Serif JP → serif）のみを使用しています。

- iOS / macOS / Windows：内蔵の明朝が当たり、意図通りの表示
- **一部のAndroid：明朝が無く、ゴシックにフォールバックする**（コンセプトの印象が弱まる）

Webフォント（Noto Serif JP）を読み込めば全端末で明朝に揃いますが、
CJKフォントは容量が大きく、表示速度とのトレードオフになります。
フォント指定の**最後**に置けば内蔵明朝がある端末ではダウンロードが発生しないため、
影響はAndroid等に限定できます。

**Performance ルールを受領後に判断が必要です。**（現状は速度優先で未導入）
