# 燻製塩焼鳥 けむり｜提案用デモサイト

**RIKKUN WEB STUDIO が「燻製塩焼鳥 けむり」へ営業するためのデモページ**です。
店舗の実サイトではありません。

---

## このサイトの役割

店舗紹介サイトではなく、**注文前の不安を減らすテイクアウト注文案内ページ**として設計しています。

GoogleやInstagramから来た初めてのユーザーが

何の店？ → 何が特徴？ → 何を注文できる？ → どうやって注文する？ → どこで受け取る？ → 電話してみよう

まで迷わず進めることを目的にしています。

- **Primary CTA**：電話で注文する（`tel:09044731867`）
- **Secondary CTA**：本日のメニューを見る（Instagram）／場所を見る（Google Maps）

## デザイン

**コンセプト：「夕方、煙が立つ。家に持ち帰る焼鳥。」**

ロゴの視覚的特徴（黒・白・黄・赤・鶏・煙・和風）をVisual DNAとして扱っています。

### 色

| 役割 | 色 | 使いどころ |
|---|---|---|
| Base | `#11171A` `#171A1C` | 全体の地。墨色 |
| Light | `#F4F0E8` `#FFFFFF` | 反転させるセクション |
| Accent Yellow | `#F4D000` | 燻製塩・重要情報の小さなアクセント |
| Accent Red | `#D92C20` | 電話注文CTAのみ |
| Smoke Brown | `#604A3C` | 生成り面の小見出し・煙の陰影 |

使用順序は 墨 → 生成り・白 → 黄 → 赤。
**赤は電話CTA以外に使っていません。**黄も面では使わず、罫・タグ・強調の線のみです。

### タイポグラフィ

見出しは明朝、本文はゴシック。日本語を主役にし、英字は装飾として使っていません
（セクションラベルもすべて日本語）。数字は `tabular-nums`。

### レイアウト

左右非対称を基本にし、余白の量をセクションごとに変えています。
3カードの連続、全中央揃え、巨大な英字、SaaS風の白背景＋カード量産は使っていません。

- **WHY KEMURI** は3つの特徴を並べず、
  燻製塩 → 注文を受ける → 焼く → 焼き立てを受け取る → 家へ持ち帰る を
  **黄色い一本の線でつないだ流れ**として構成（PCは横、SPは縦）
- **注文方法**はカードではなく罫線で区切った4項目
- 煙のモチーフは細い線のみ。Blobや炎のイラスト、炎のアニメーションは使っていません

## 画像について

**実店舗写真・料理写真はAIで生成していません。**

素材のご提供がまだのため、該当箇所は
「実店舗写真／ご提供待ち」と明示した**写真枠**として設計しています（HERO・受け取り・アクセスの3箇所）。
写真が届き次第、枠をそのまま差し替えられます。

料理写真がないぶん、メニューはタイポグラフィと余白で構成しています。

`assets/img/logo.svg` も**実ロゴデータ未提供のため仮のマーク**です。
ブリーフに記載のあった特徴（黒・白・黄・赤・鶏・煙・和風）に沿って作成しています。正式データへの差し替えが前提です。

## 店舗確認が必要な項目

未確認の情報は掲載せず、画面上に「店舗確認後に掲載」と表示しています。

| 項目 | 現在の扱い |
|---|---|
| 営業時間 | 店舗確認後に掲載（本日の営業はInstagramへ誘導） |
| 定休日 | 店舗確認後に掲載 |
| 各商品の価格 | 店舗確認後に掲載 |
| 注文の受付時間 | 店舗確認後に掲載 |
| 焼き上がりまでの目安時間 | 店舗確認後に掲載 |
| 人気商品・おすすめ | 断定せず、「選びやすい定番」という案内にとどめる |
| 駐車場 | 「店舗正面に3台」を掲載。台数・停め方は最終確定待ちと明記 |

掲載している商品は確認できた7品のみです。架空の商品は追加していません。

### 構造化データ

`Restaurant` で**確認済みの項目（店名・住所・電話・Instagram）のみ**登録しています。
営業時間は未確認のため `openingHoursSpecification` を入れていません。
店舗確認後にそのまま追記できる形にしてあります。

## 実装

- **ライブラリ・外部リクエストゼロ**。HTML / CSS / JS のみ。Webフォントも読み込まず端末内蔵フォントを使用
- **JS無効でも全内容が読め、電話できる**（`html.js` クラスによるプログレッシブ・エンハンスメント）
- 画像はSVG（ロゴのみ）。`width` / `height` を指定しCLSを防止。フッターのロゴは `loading="lazy"`
- `prefers-reduced-motion: reduce` でモーション全停止
- スキップリンク、`:focus-visible`（黄のリング）、`tel:` リンク、外部リンクは `rel="noopener"`
- 文字色は本文・補足とも **WCAG AA（4.5:1）以上**
  （墨地の補足 5.36:1 ／ 生成り地の補足 5.17:1 ／ 赤CTAの白文字 4.85:1）
- SPの固定CTAは `env(safe-area-inset-bottom)` を考慮し、フッターに同じ高さの余白を確保して内容を隠さない

### 検証済み

320 / 390 / 768 / 860 / 1024 / 1440 / 1920px で横スクロールなし・要素のはみ出しなし。
コンソールエラー、ネットワークエラーともにゼロ。
reduced-motion、JS無効、キーボード操作を実ブラウザで確認。

### 既知の注意点

見出しの明朝体は端末内蔵フォント（Hiragino Mincho ProN → Yu Mincho → Noto Serif JP）に依存します。
iOS / macOS / Windows では意図どおりですが、**一部のAndroidでは明朝が無くゴシックにフォールバック**します。
全端末で揃える場合はWebフォントの読み込みが必要で、表示速度とのトレードオフになります。
