# 燻製塩焼鳥 けむり｜提案用デモサイト

RIKKUN WEB STUDIO が店舗様へご提案するためのデモページです。店舗の実サイトではありません。

---

## 目的

「おしゃれな飲食店サイト」ではなく、**電話注文への到達**を最重要KPIとした注文案内ページ。

どんな店？ → 何が特徴？ → 何を注文できる？ → どうやって注文する？ → どこで受け取る？ → 電話する

**PRIMARY CTA：「電話で注文する」**（`tel:09044731867`）— ページ内9箇所に配置。

---

## デザインコンセプト

**「夕方、煙が立つ。家に持ち帰る焼鳥。」**

高級焼鳥店ではなく、地域にある知る人ぞ知る焼鳥屋。仕事帰りに買って帰りたくなる感覚を表現しています。

### 色（指定値どおり）

| 役割 | 色 | 使いどころ |
|---|---|---|
| Dark Navy | `#11171A` | 主体 |
| Cream | `#F4F0E8` | 主体 |
| Yellow | `#F4D000` | ブランドアクセント（少量） |
| Red | `#D92C20` | CTA・重要情報のみ |
| Smoke Brown | `#604A3C` | 罫・小見出し |

Dark Navy と Cream を交互に敷き、**赤はCTAと警告のみ**、黄は section番号・強調語・罫のみ。面では使っていません。

### タイポグラフィ

見出しは明朝（Noto Serif JP ＋ 端末内蔵の游明朝／ヒラギノ明朝）、本文はゴシック。
セクション見出しもすべて日本語で、装飾目的の英字は使っていません。

### 指示書で明示された禁止事項への対応

- **02 は「4枚のカード」にしない** → カードの地と枠を持たせず、矢印でつながる流れとして実装（PCは横、SPは縦）
- **03 は3カードを使わない** → 「燻製塩 → 焼く → 持ち帰る」を黄色の一本線でつないだ1本のストーリーとして実装
- 巨大グラデーション・Blob・過剰な英字・中央揃えだらけ・黒×金・赤×黄の大量使用は不使用

## 店舗確認が必要な項目（TO CONFIRM）

未確認の情報は掲載せず、画面上に「店舗確認後に確定します」と明示しています。

- 価格・メニューの全ラインナップ
- 営業時間 / 定休日
- 注文の受付時間 / 焼き上がりまでの目安
- 駐車台数・受け取りの詳細

掲載しているメニューは指示書に記載の8品のみです。架空の商品は追加していません。

> 補足：以前いただいた資料では「もも・豚バラ・ねぎま・つくね・レバー・砂ずり・スモークチーズ」でしたが、
> 今回の指示書（08 MENU）の8品（もも／レバー／せせり／すなずり／はりかわ／うずらのたまご／はつ／ウインナー）を採用しています。
> どちらが最新か、店舗確認時にあわせてご確認ください。

### 構造化データ

`Restaurant` で**確認済みの項目（店名・住所・電話・Instagram）のみ**登録。
営業時間は未確認のため `openingHoursSpecification` を含めていません。

## 実装

- ライブラリ非依存。HTML / CSS / JS のみ
- 外部リクエストは見出し用の Noto Serif JP のみ（`display=swap`、端末に明朝がある場合はダウンロードされません）
- **JS無効でも全内容が読め、電話できる**（`html.js` によるプログレッシブ・エンハンスメント）
- SP固定CTAは**常時表示**。`env(safe-area-inset-bottom)` に対応し、フッターに同じ高さの余白を確保して内容を隠しません
- モーションは最小限（hero fade / scroll reveal / CTA hover のみ）。パララックス・炎・パーティクルは不使用
- `prefers-reduced-motion: reduce` でモーション全停止
- スキップリンク、`:focus-visible`（黄のリング）、`tel:` リンク、外部リンクは `rel="noopener"`

### 検証済み

320 / 375 / 768 / 1080 / 1280 / 1440 / 1920px で横スクロール・はみ出しなし。
コンソールエラーなし。reduced-motion、JS無効、キーボード操作、固定CTAのフッター干渉を実ブラウザで確認。

コントラストは全項目 **WCAG AA（4.5:1）以上**。
（濃紺地の補足 5.70:1 ／ 生成り地の補足 4.87:1 ／ 赤CTAの白文字 4.85:1 ／ 警告文 5.42:1）

### 既知の注意点

見出しの明朝は Noto Serif JP を読み込んでいますが、ネットワークが使えない環境では
端末内蔵の明朝（ヒラギノ明朝／游明朝）にフォールバックします。どちらでも表示は崩れません。
