# 燻製塩焼鳥 けむり

鹿児島県霧島市国分の焼鳥テイクアウト店「燻製塩焼鳥 けむり」のサイト。
React + Vite + Framer Motion。

> RIKKUN WEB STUDIO｜提案用デモ

---

## 考えたこと

店の情報を眺めていて、三つのことが引っかかりました。

**一つめ。店名が「けむり」であること。** 煙そのものが看板です。
なら画面でも、模様ではなく本物の煙を立てるべきだと考えました。

**二つめ。営業が1日5時間しかないこと。**
17:00に火を入れて、22:00に閉める。売り切れたらそこで終い。火曜と水曜は休み。
つまりこの店は「開いている時間のほうが短い」。
だとすれば、客が最初に知りたいのは味でも場所でもなく **「今、やってる？」** です。

**三つめ。写真がないこと。**
これは弱点に見えて、実は方向を決めてくれました。
焼鳥屋のサイトは料理写真で殴るのが定石ですが、それができない。
ならば **文字・縦組み・煙・熾火だけで組む** と決めました。
結果、他の焼鳥屋に流用できないサイトになっています。

## やったこと

### 1. 「今、やってる？」に最初に答える

ヒーローの右側（スマホでは見出しのすぐ下）に、**今この瞬間の店の状態**を出します。
営業時間と定休日だけから組み立て、30秒ごとに更新します。

| 状態 | 表示 | 電話ボタン |
|---|---|---|
| 火・水 | 本日は定休日 | 本日は定休日です |
| 開店90分以上前 | 本日は 17:00 から ／ あと◯時間 | 電話で注文する |
| 開店90分以内 | まもなく火を入れます ／ あと◯分 | 電話で注文する |
| 17:00–21:00 | いまは営業時間です ／ のこり◯時間 | 電話で注文する |
| 21:00–22:00 | まもなく 22:00 です ／ のこり◯分 | **電話で在庫を確認** |
| 22:00以降 | 本日は終了しました ／ 明日は 17:00 から | 電話で注文する |

基準は**見ている人の端末ではなく日本時間**（旅行中でも店の時間で表示されます）。

17:00→22:00 の5時間を一本の線にして、今どこにいるかを熾火の点で示しています。
これは**時間の線で、在庫の残量ではありません**。

### 1-b. 売切れ次第CLOSE をどう扱ったか

この店でいちばん難しいのがここです。**サイトは在庫を知りません。**

| | わかること | わからないこと |
|---|---|---|
| 判断材料 | カレンダーと時計 | 店の在庫 |
| 答えるのは | このサイト | 店（電話・Instagram） |

だから**「営業中」とは言い切らず**、時計の話と在庫の話を混ぜずに並べています。

- 見出しが言うのは時刻のことだけ（「いまは営業時間です」＝時間内、という意味しか持たせない）
- その下に**熾火の縦罫で区切った「在庫」ブロック**を、見出しと同じ重さで置く。
  灰色の小さな注記にすると、21時に見た人が閉まった店に向かってしまいます
- **閉店1時間前から言い方が変わります。**
  見出しは「まもなく 22:00 です」、在庫ブロックは「売り切れた時点で閉店します。向かう前に、お電話でご確認ください」、
  電話ボタンの用件も「注文」から「**在庫を確認**」へ。リンク先の番号は同じです
- 「買い方」にも一行入れました ——「売り切れていないかを先に確かめられるのも、電話だけです」

やらなかったこと：

- **「たぶん売り切れです」のような推測はしません。** 在庫が減ることは確かでも、
  何時に売り切れるかは店にしか分かりません。推測で客足を止めるのは本末転倒です
- **店が毎日「本日分終了」を押す仕組みは入れていません。** いちばん正確ですが、
  5時間の営業中にスマホを触る手間が増えます。押し忘れた日は嘘になるので、
  かえって信用を落とします。すでに続いている Instagram の告知にそのまま渡すほうが確実です

### 2. 煙を本物にする

`<canvas>` で粒を上らせています。負荷は抑えました。

- 粒は22個。やわらかい円を1枚だけ作って使い回す
- 解像度は最大1.5倍まで（高精細端末でも塗る面積を増やさない）
- 30fps。**画面外・非表示タブ・reduced-motion では完全に停止**
- 実測：スクロール中 60fps（375 / 1600px）

### 3. 品書きは木札で

7品を**縦書きの木札**として並べました。料理写真の代わりです。
縦書きは `writing-mode` ではなく1文字=1ブロックで積んでいます（明朝が無い端末で字送りが崩れないため）。

### 4. 店の場所は、写真より図で

「どこに停めて、どこで受け取るか」は写真より図のほうが速いので、
店・受け取り口・店前の駐車・道路の関係を線画にしました。

## 構成

```
src/
  lib/now.js            営業状態の判定（純関数・時刻偽装でテスト可能）
  data/site.js          店舗情報（文言はここに集約）
  components/
    Smoke.jsx           canvasの煙
    Now.jsx             今の状態
    Tate.jsx            縦書き
    Sections.jsx        6セクション
    Chrome.jsx          ヘッダー・下部の電話・フッター
    Motion.jsx          共通のモーション
  styles/global.css
```

セクションは6つだけです。5時間しか開かない持ち帰り専門店に11セクションは要らないと判断しました。

いま → けむりのこと → 品書き → 買い方 → 店 → 締め

```sh
npm install && npm run dev
npm run build && npm run preview
```

## 色と文字

| 役割 | 色 |
|---|---|
| 夜 | `#0A0C0E` / 藍の闇 `#141C26` |
| 和紙 | `#EDE7DA` |
| 火 | `#E2502B`（電話とCTAだけ） |
| 熾火 | `#F0A03C`（今の状態・小見出し） |

### 書体

見出しは **Kaisei Tokumin（解星 篤ミン）**。本文はゴシック（端末標準）。

端末標準の明朝は「どの明朝でもいい」顔をしていて、店の性格が出ませんでした。
Kaisei Tokumin は**墨が乗って終筆が膨らむ**ので、手書きの看板や木札に近い質感が出ます。
Zen Old Mincho も試しましたが端正すぎて「老舗」寄り、しっぽり明朝は無難すぎたため見送りました。

書体に合わせて字間も詰めています（従来 `.04em` → `.015em`）。
太い書体は字面が大きいので、元の字間だと間延びするためです。
小さく出る明朝は500、見出しは700で使い分けています。

### 重さの話

CJKフォントは丸ごと読むと数MBあります。Google Fonts のまま使うと、
このサイトが使う文字は72チャンクに散らばっていて **約1.1MB** 落ちてきます。
地元の店のサイトでモバイル1MBは論外なので、**サイトで実際に使う394文字だけに絞って同梱**しました。

| | サイズ |
|---|---|
| Google Fonts のまま | 約 1,100 KB |
| 394文字に絞って自前配信 | **159 KB**（500 + 700 の2ウェイト） |

- 外部ドメインへの要求は**ゼロ**（自前配信。接続やTLSの往復も無くなります）
- `font-display: swap` で、読み込み中も端末の明朝で読めます
- 差し替えによるレイアウトのズレ（CLS）は **0.0003**＝実質なし

文言を変えて新しい漢字が増えた場合は作り直しが必要です。
手順は [`src/assets/fonts/NOTICE.md`](src/assets/fonts/NOTICE.md) に残しました。
ライセンスは SIL OFL 1.1（サブセット化・再配布可）。

## 検証済み

- 320 / 375 / 768 / 920 / 1280 / 1600px で横スクロールなし、コンソールエラーなし
- 営業状態7パターンを時刻を偽装して確認（定休日・開店前×2・営業中・閉店1時間前・閉店直前・終了）
- `prefers-reduced-motion` で煙を完全停止、隠れる本文ゼロ
- Escでメニューが閉じる、最初のTabがスキップリンク
- 下部の電話バーがフッターを隠さない
- 電話リンクはすべてタップ領域44px以上
- スクロール中 60fps、フォント差し替えによるCLS 0.0003
